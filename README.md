# Mitali Talukdar — Web Developer Portfolio

Responsive portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Learnify screenshots
The `assets/` folder contains the actual Learnify screenshots supplied for the portfolio:
- Public homepage
- Admin dashboard
- Faculty applications
- Payment management
- Course management
- Student dashboard
- Four mobile app screens

## Before publishing
- Check all project descriptions and technology claims for accuracy.
- Add the Learnify GitHub repository URL if it is public.
- Add LinkedIn once the profile is complete.
- If you have a live deployed demo, add its URL.
- Do not publish screenshots containing real user personal information; blur or crop any private data first.

## Publish with GitHub Pages
Push the contents of this folder to a GitHub repository. In repository Settings, open Pages and select the branch/folder to publish.
